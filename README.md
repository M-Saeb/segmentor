# Segmentor

## Installation

### 1. Prerequisite

Please install conda beforehand and activate it. [link](https://docs.conda.io/projects/conda/en/latest/user-guide/install/index.html)

### 2. Setup Environment

Run the command 
```bash
conda env create -f environment.yml
```

## Run the program
In the run `run.sh` file setup the following variables
1. `PYTHON_PATH`
2. `INPUT_FILE`
3. `OUTPUT_FILE`

Once you setup these variables, run the command:

```bash
bash run.sh
```
