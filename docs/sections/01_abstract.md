# Abstract

We present **Segmentor**, an interactive, four-stage system for semantic segmentation of large-scale LiDAR point clouds, with integrated Vision Language Model (VLM) inference for object identification and 3D city model export. The system decomposes the processing task into four sequential, user-guided stages: (1) a **Pre-processing** stage that performs noise removal, voxel downsampling, and spatial reordering using KD-tree-based binning to produce geometrically coherent processing tiles; (2) a **Segmentation** stage where the user tunes and confirms RANSAC-based detection of structural surfaces — ground, ceiling, and walls — with real-time preview feedback before committing to a full-file run; (3) a **VLM Clustering** stage that applies DBSCAN to residual unclassified points and routes per-cluster isometric renderings to a locally hosted Vision Language Model to semantically label discrete objects (e.g., vehicles, furniture); and (4) an **Exporting** stage that reconstructs triangle meshes from each classified surface type using a custom iterative ball-neighbourhood algorithm and writes the result to a CityJSON v2 file. The system follows a strict Model–View–Controller (MVC) architecture, enabling both interactive GUI use and headless script execution.
